# Security

If you find a security issue, use GitHub's private vulnerability reporting for this repository. Please avoid posting exploit details in a public issue. Include the affected route, expected behavior, and a minimal reproduction when possible.

Supported branch: `main`.

Private GPX files and images must remain behind authorization checks. A route with endpoint hiding enabled must omit the hidden coordinates from maps, public GPX downloads, and elevation interactions. Changes to these rules need focused tests.
